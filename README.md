# Cairns Badminton Club website concept

A modern, responsive redesign concept for the Cairns Badminton Club website.

## Preview

Public concept: https://concept-cairns-badminton-site.shivam-cool682.chatgpt.site

## Files

- `index.html` — page content and structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and venue fee selector
- `assets/club-court.jpg` — illustrative badminton photograph

The booking buttons currently link to the club's existing booking and information pages.

## Local preview

Open `index.html` in a web browser.
